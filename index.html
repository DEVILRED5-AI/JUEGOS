Conexión con GitHub

Para publicar juegos la app necesita un token con permiso solo sobre el repositorio . Se guarda únicamente en este dispositivo.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Ponle un nombre (Mis Juegos) y una fecha de vencimiento.
  3. Repository access → Only select repositories → elige JUEGOS.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.
